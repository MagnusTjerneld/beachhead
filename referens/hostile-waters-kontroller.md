# Hostile Waters: Antaeus Rising, kontrollschemat

Sparat 19 okt 2026 som förebild för manuell styrning av HÖK och övriga enheter (issue 64). Magnus: ingen idé att uppfinna hjulet igen, de har lagt arbete på att göra det intuitivt. Tangenternas funktioner är fria att använda; manualens text, ikoner och grafik är det inte, så allt nedan är vår egen sammanfattning.

Källa: spelets manual hos Steam, sidorna 6 till 24 (https://cdn.akamai.steamstatic.com/steam/apps/267980/manuals/Hostile%20Waters%20Manual.pdf). En spelares referenskort finns på https://steamcommunity.com/sharedfiles/filedetails/?id=2101864210 (inte läst, Steam svarade 429).

## Att styra ett fordon (s. 6)

Samma tangenter för markfordon och flyg.

| Tangent | Funktion |
|---|---|
| W / S | Fram / bak |
| A / D | Strafe vänster / höger |
| Q / E | Sjunk / stig (kollektivet, bara flyg) |
| Mus | Vrider tornet; fordonet följer tornet som standard (tornlås) |
| Vänster musknapp | Skjut. Bärgningsfordonet bärgar och lyfthelikoptern vinschar med samma knapp |
| Höger musknapp | Intelligent målval (se nedan) |
| Mittenknappen | Tornlåset av och på: av = se sig om fritt utan att fordonet vänder |

- Autopiloten släpper så fort man trycker en riktningstangent.
- Varje fordon bär bara ett vapen (s. 14), så vapenbyte finns inte.

## Byta fordon och följa andra (s. 6 och 7)

| Tangent | Funktion |
|---|---|
| Sikta på en egen enhet + Enter | Ta över den |
| Siffertangent två gånger | Ta över enheten eller gruppen på den siffran |
| Shift + siffra | Visa en annan enhets kamera i en ruta medan man styr sin egen; samma igen stänger |

Överst på skärmen ligger en rad ikoner för de egna enheterna; den styrda är markerad och något upphöjd.

## Mål (s. 7 och 8)

| Tangent | Väljer |
|---|---|
| T | Alla mål |
| Tab | Målet närmast siktets mitt |
| H | Närmaste fiende |
| R | Närmaste resurs |
| B | Närmaste byggnad |
| M | Närmaste uppdragsmål |
| J | Närmaste fiende som skjuter på mig |
| G | Släpp alla mål |

- Höger musknapp beror på fordonet: med vapen närmaste fiende, med bärgning närmaste resurs, i lyfthelikoptern närmaste egna enhet.
- Flera tryck på samma tangent eller knapp stegar mellan målen av samma slag, från närmast till längst bort. Man kan byta målslag utan att släppa först.
- Siktet: grönt utom räckhåll, rött inom räckhåll, rött med fyra pilar när målet är låst. Låset släpper utom räckhåll eller när målet kommer för långt från siktets mitt; hur långt beror på vapnet.
- N: ljusförstärkning i mörker och dåligt väder.

## Rummen och spelet (s. 9 och 24)

| Tangent | Funktion |
|---|---|
| F1 | Krigsrummet (sjökortet) och tillbaka till fordonet |
| F2 | Byggrummet och tillbaka |
| F3 | Inställningar, spara och ladda |
| F6 / F7 | Snabbspara / snabbladda |
| Mellanslag | Ordergränssnittet av och på |
| Esc | Hoppar över introfilmen |
| F8 | Konsolen (fusk, kräver startparametern -setusupthebomb) |

Spelet står still i krigsrummet, byggrummet och inställningarna, så de används också som paus för att hinna planera; ordrar som ges där utförs när man går tillbaka till ett fordon.

## Krigsrummet, sjökortet (s. 17 och 18)

| Inmatning | Funktion |
|---|---|
| Vänster musknapp | Välj enhet; dra en ruta för flera |
| Mittenknappen | Flytta kartan framåt och bakåt |
| Höger musknapp, håll och dra | Vrid kartan och ändra vinkeln |
| Höger musknapp, ett klick | Avmarkera |
| Piltangenterna | Flytta kartan |
| + / - | Zooma |
| Ctrl + 1 till 9 | Gör de markerade till en grupp; nya enheter får automatiskt en siffra |
| Siffra | Välj gruppen |
| Shift + dra | Lägg till upp till tio punkter till en rutt (röd, grön eller blå) |

Färger på kartan: röd fientlig enhet, mörkröd fientlig byggnad, grön egen enhet, cyan resurs, gul uppdragsmål.

## Ordergränssnittet (s. 19 till 22)

Ordrar byggs som en mening i tre steg: välj enheten (siffertangent), välj ordern, välj mål eller plats. När gränssnittet är uppe har man bara tornet kvar i det egna fordonet. Siffertangenterna fungerar också som mål i steg tre (till exempel laga enhet 3).

- Mål: MIG, MIN POSITION, MITT MÅL (det man siktar på) och DÄR JAG TITTAR (platsen under siktet).
- Ordrar: anfall och anfall till (en plats: förstör allt på vägen och slåss sedan fritt där), flytta till (utan att stanna för strid; till en enhet = följ den, "var min wingman"), håll position, bärga och laga (och till en plats), hämta upp och sätt ned, samlingspunkt, rutter, tillbaka till skrotaren, töm orderkön, bakåt en meny, avfyra fartygets kanoner.
- Utan order slåss beväpnade enheter fritt ("frenzy"), först mot fiender och sedan byggnader; bärgare och lagare håller sig nära där de står. Håll position stoppar det.

## Referenskortet, med ordergränssnittet uppe

Från spelets tryckta referenskort (Magnus foto 19 okt, samma kort som Steam-guiden 2101864210, bilden "com int enabled"). Siffertangenterna: ett tryck visar enheten och ger order, två tryck tar över den. Kortet för körläget, med ordergränssnittet nere, saknas ännu.

| Tangent | Funktion |
|---|---|
| Esc | Avbryt, hoppa över film |
| F1 / F2 / F3 | Krigsrummet / byggrummet / inställningarna |
| F5 eller P | Paus |
| F6 / F7 | Snabbspara / snabbladda |
| ` (vänster om 1) | Välj fartyget |
| 1 till 0 | Enhet eller grupp; två tryck tar över |
| - / = | Zooma ut / in på kartan |
| Backspace | Stryk orderkön för enheten |
| Q | Till krigsrummet |
| W | Byggrummet |
| E | Stryk alla order / inställningar |
| A | Tillbaka till fartyget för återvinning |
| S | Byt sida i ordergränssnittet |
| D | Navigationspunkter och samlingspunkt |
| X | Anfall till |
| Z | Zoomkikaren och fartygets kanon |
| C | Kamouflera enheten |
| Mellanslag | Ordergränssnittet av och på |
| Enter | Ta över den egna enhet man siktar på |
| Ctrl | AI-styrning av och på för enheten man styr |
| Shift + målval | Stegar mellan giltiga mål |
| Shift + siffra | Visa vad enheten ser medan man slåss själv |

Målval enligt kortet (gäller i båda lägena): Tab målet närmast siktet, R närmaste resurs, T stega genom alla mål, Y målet närmast siktet, F närmaste egna enhet, G släpp alla mål, H närmaste fiende, J närmaste fiende som anfaller dig, B närmaste byggnad, M närmaste uppdragsmål, N mörkersikte.

Skillnader mot manualen: kortet har också F5 och P för paus, Backspace för att stryka orderkön, Ctrl för att låta AI:n styra enheten man sitter i, ` för fartyget, - och = för kartzoom, Y och F som målval, C för kamouflage och Z för kikaren. Med ordergränssnittet uppe betyder Q W E A S D annat än i körläget, alltså samma tangenter i två lägen.

## Att jämföra med vårt spel

- A och D som strafe och musen som sikte med fordonet låst efter det: rakt över till HÖK (issue 64).
- Q och E för höjd: krockar med våra Q (byt vyer) och E (ta över, släppa) men kan få ny betydelse i manuellt läge, med T kvar för att släppa.
- Högerklick som stegar mellan mål, och siktet som byter färg vid räckhåll och lås: saknas hos oss.
- Våra B H V K (inkallning) krockar med deras B H M J (målval); deras målval är bara i fordonet, våra inkallningar gäller överallt.
- Deras orderspråk liknar vårt hjul (vem, sedan vad), och "håll position" liknar vår Halt-knapp, som vi föreslagit på Delete. Deras Backspace stryker orderkön, alltså vår Halt; Backspace är ledig hos oss.
- Ctrl för att låta AI:n ta över enheten man sitter i liknar vårt släpp (E/T) men låter enheten fortsätta själv.
